# Agent Instructions

Before completing any change that affects Google Play review posture, check
`docs/google-play-risk-register.md`.

Update the risk register when a change adds or modifies any of these areas:

- External Petdex content, UGC/fan-work display, report links, takedown flows,
  or rights complaint handling.
- Install/Open in app links, deep link behavior, custom schemes, App Links, ZIP
  URLs, downloadable assets, or browser-to-app handoff behavior.
- Network destinations, static JSON generation, Petdex API usage, GitHub Pages
  deployment, privacy wording, or content policy wording.
- Third-party copied/adapted code, MIT license notices, or attribution.

If a change was reviewed and no update is needed, say this in the final work
summary:

`Google Play risk register: no update needed`

Do not treat the risk register as legal advice. It is an engineering record to
keep Play review, disclosure, and takedown risks visible.
